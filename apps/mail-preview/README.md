# Mail Preview

Minimal Maizzle app for previewing email templates from `@repo/mail` in the browser.

## Development

```bash
pnpm dev
```

Starts the preview server at **http://localhost:3005**. Edit templates in `packages/mail/emails/` and see changes live.

## Build

```bash
pnpm build
```

Compiles production-ready emails to `build_production/`.
